# Les commentaires avec python

Pour commenter une ligne, on utilise `#`. Pour commenter plusieurs lignes, on délimite les lignes avec `"""`. On peut aussi utiliser `#` pour écrire un commentaire sur plusieurs lignes.

```python
# Ceci est un commentaire sur une ligne

"""
Ceci est
un commentaire
sur
plusieurs
lignes
"""
```

Le recourci clavier pour commenter/décommenter une ligne ou un bloc de code est `Ctrl + /`.
