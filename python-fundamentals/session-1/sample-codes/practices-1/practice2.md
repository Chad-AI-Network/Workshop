# REPL = Read Evaluate Print Loop

Pour lancer le REPL de Python, on entre `python` dans le terminal (ou invite de commande) et on valide (en appuyant sur `Entrer`).

```bash
python
```

La ligne après exécution de la commande devrait ressembler à

```bash
>>>
```

Pour afficher la table de multiplication, on peut entrer `5*1` puis valider, ensuite `5*2`, ...

```python
5 * 1
```
